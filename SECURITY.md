# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Report them
privately to the maintainer through the project’s contact channel or by
email if available.

Include:

- A description of the issue and its potential impact.
- Steps to reproduce.
- Affected files or routes.
- A suggested fix, if you have one.

## Response

The maintainer will acknowledge reports as soon as practical, investigate,
and publish a fix. Please allow reasonable time for triage before disclosure.

## Scope

This is a static site. Typical concerns include exposed assets, unsafe links,
client-side injection in dynamically rendered content, and third-party
resource handling.
